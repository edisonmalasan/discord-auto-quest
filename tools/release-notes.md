Discord Auto Quest 1.2.0 for Windows x64: Windows 10/11 and stable Discord desktop.

Downloads:
- Setup EXE: current-user installation, with WebView2 provisioning if needed.
- Portable ZIP: extract all files; requires Microsoft Edge WebView2 Runtime.
- Setup EXE signature and latest.json: authenticate confirmed in-app updates.
- SHA256SUMS: SHA-256 integrity checks for the other four assets.

The installer has an updater signature, not a Windows Authenticode signature. Windows may still warn about the publisher. Do not disable Windows security protections. Linux and macOS are not supported releases.

Work continues across supported accepted quests until stopped, recovering its queue from Discord's current state. Completion is reported only after Discord confirms it. Optional completion notifications are disabled by default and available in the installed Windows app. About includes update checks; installing a newer stable release requires confirmation and a confirmed backend Stop. Portable builds download newer releases manually.

Available now includes only confirmed positive Orbs rewards, regardless of game or amount. Other reward types remain visible in Ongoing and Completed. Mixed rewards can appear in Available, but acceptance of special or mixed offers continues in Discord.

Supported Desktop/Xbox/PlayStation OR offers can be reviewed with Desktop intent. After acceptance the app selects Desktop and verifies the native result. Eligible already accepted quests expose Use Desktop. Console-selected quests continue in Discord. If acceptance succeeds but selection is unconfirmed, refresh and recover selection without accepting again.

Acceptance leaves quests idle while Work is stopped. When continuous Work is already enabled, the confirmation explains that the accepted quest joins its queue only after required Desktop selection is confirmed. Unsupported offers and reward claims continue in Discord. Some quest tasks require user participation. Discord updates can interrupt compatibility. Exact 1.2.0 packaged acceptance and Desktop selection, notifications, and update/recovery scenarios remain pending until the release's acceptance evidence is recorded.

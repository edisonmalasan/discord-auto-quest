Discord Auto Quest 1.2.1 for Windows 10/11 x64 and stable Discord desktop.

This patch strengthens content protection and release verification while preserving the existing quest workflows. These measures increase copying effort and do not guarantee secrecy against determined reverse engineering.

Downloads:
- Setup EXE: current-user installation with WebView2 provisioning when needed.
- Portable ZIP: extract all files; requires Microsoft Edge WebView2 Runtime. Portable copies receive download links.
- Installer signature and latest.json: authenticated in-app update delivery for installed copies.
- SHA256SUMS: download integrity checks; not publisher identification.

The build is unsigned by a Windows publisher. Do not disable Windows security protections. Linux is excluded and macOS remains paused. Updates require confirmation and confirmed Work cleanup. Rewards remain claimable only in Discord.

Exact 1.2.1 packaged installation, live workflows, notifications, and update/recovery checks remain pending. Historical test results do not establish those outcomes. Keep this release in draft until its required checks pass.

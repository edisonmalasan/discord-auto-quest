Discord Auto Quest 1.2.2 for Windows 10/11 x64 and stable Discord desktop.

This patch dismisses acceptance feedback after five seconds and restores in-app acceptance and Desktop selection for supported offers with compatible client metadata. The fixes apply through shared validation, independently of quest names or Orb amounts.

Accept quest still requires your review and confirmation. Supported Desktop/console alternatives select Desktop and verify Discord's selection afterward. If Discord accepts the quest while its review is open, confirmation can finish Desktop selection without enrolling again. Acceptance never enables Work; an already enabled continuous session can queue the confirmed quest. Unknown requirements and Console-selected quests retain a Discord handoff.

Downloads:
- Setup EXE: current-user installation with WebView2 provisioning when needed.
- Portable ZIP: extract all files; requires Microsoft Edge WebView2 Runtime. Portable copies receive download links.
- Installer signature and latest.json: authenticated in-app update delivery for installed copies.
- SHA256SUMS: download integrity checks; not publisher identification.

The build is unsigned by a Windows publisher. Do not disable Windows security protections. Linux is excluded and macOS remains paused. Updates require confirmation and confirmed Work cleanup. Rewards remain claimable only in Discord.

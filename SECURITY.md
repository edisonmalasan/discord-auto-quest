# Security policy

Only the latest Windows beta is eligible for fixes during the beta period. Linux and macOS are not supported releases.

Report vulnerabilities privately to edisonmacaraegmalasan@gmail.com. Include the affected version, reproduction steps, and impact. Do not send account tokens, private messages, or unredacted account data. Do not open a public issue for an undisclosed vulnerability. No response-time guarantee or paid bounty is offered.

The app interacts with the user's local Discord desktop client and loads quest artwork from Discord's media services. External action links open the user's browser or Discord. The app does not ask for a Discord password or token. Beta builds are unsigned; checksums verify file integrity, not publisher identity. Local connectivity is intended for loopback only. Do not expose it to a network.
